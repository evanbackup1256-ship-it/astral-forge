# Production IDs Checklist

These IDs cannot be generated by code. They must be created in Roblox Creator
Dashboard / Asset Manager (or uploaded with the scripts in `tools/`) and then
pasted into the source tree. The game warns at startup until they are populated.

## Prop kit model (done)

Used by `src/Server/AstralForge/PropKitLoader.luau` (the old casino kit loader,
renamed when the casino became the Bazaar). `src/Shared/AstralForge/Shared/PropKit.luau`
already holds the uploaded kit (`Id = 95516912278016`, `KitReady = true`).

## Crate kit models (done)

Used by `src/Server/AstralForge/CrateKitLoader.luau`; the ids are in
`src/Shared/AstralForge/Shared/CrateKit.luau`: the original kit (`Id = 88755990794383`,
20 skins) and the expansion kit (`Expansions[1].Id = 78427750379265`; Cinder, Verdant,
Tidal, Runic, Comet, Mirage, Quasar, Bastion, Eclipse, Nova, Halo). Any skin without a
mesh falls back to the procedural crate in `src/Client/AstralForge/CrateDetails.luau`.

To rebuild the expansion:

1. `& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' -b --python tools\cratebuild\build_expansion.py`
   (`FAST=1` for quick untextured previews; `CPU=1 TEX=512 SAMPLES=16 NOPREVIEW=1 THREADS=6` for a
   CPU-only bake while Roblox is open. Keep Blender at normal priority: below-normal starves it.)
2. `python tools\cratebuild\upload_expansion.py` (Open Cloud key from `tools/assetgen/set-key.ps1`).
3. Paste the printed id into `Expansions[1].Id` in `src/Shared/AstralForge/Shared/CrateKit.luau`.
