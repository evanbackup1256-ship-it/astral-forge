# Production IDs Checklist

These IDs cannot be generated by code. They must be created in Roblox Creator
Dashboard / Asset Manager and then pasted into the source tree. The game warns
at startup until they are populated.

## Casino / crate kit model

Used by `src/Server/AstralForge/CasinoKitLoader.luau` and
`src/Client/AstralForge/pages/PagesCasino.luau`.

1. Build or upload the casino/crate kit as a single Roblox model.
2. Copy the asset ID.
3. Edit `src/Shared/AstralForge/Shared/CasinoKit.luau`:
   - Set `Id` to the asset ID.
   - Set `PlaceholderId` if you want a local fallback model.
   - Set `KitReady = true`.

```lua
return table.freeze({
    Id = 0,              -- <- paste real kit asset ID here
    PlaceholderId = 0, -- <- optional local fallback
    KitReady = false,    -- <- set to true once uploaded
})
```

## Verification

After populating IDs:

1. Run `npm test`.
2. Run `argon build default.project.json -x -o "Astral Forge v2.rbxlx"`.
3. Start a Studio play test and confirm the release-blocker warnings are gone.
