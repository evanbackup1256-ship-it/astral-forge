# Docs

- [`PRODUCTION_IDS.md`](PRODUCTION_IDS.md): the Roblox asset and product ids a release needs.
- [`design-system/`](design-system/README.md): colour, type and component tokens with HTML previews.
- [`qa/`](qa/): the QA record.
  - [`TEST_PLAN.md`](qa/TEST_PLAN.md) and [`BUG_AUDIT.md`](qa/BUG_AUDIT.md): how changes get checked.
  - [`REPRO_LOG.md`](qa/REPRO_LOG.md): bugs reproduced before they were fixed.
  - [`NOT_TESTED.md`](qa/NOT_TESTED.md): what has not been verified, and why.
  - [`SIGNOFF.md`](qa/SIGNOFF.md) and [`TEST_READY.md`](qa/TEST_READY.md): what was signed off.
  - [`ORIGINAL_REQUEST.md`](qa/ORIGINAL_REQUEST.md): the brief the QA pass was measured against.
- [`reports/`](reports/): one-off write-ups of past fixes and improvement passes. They are kept for history and may describe code that has since changed.
